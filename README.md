# FuegoVibe 🔥

A native iOS application built with Swift and Xcode. FuegoVibe delivers a vibrant, high-energy mobile experience with a full test suite covering both unit and UI layers.

---

## Features

- 📱 **Native iOS** — Built entirely in Swift for smooth, performant user experience
- ✅ **Unit Tests** — Comprehensive test coverage for core logic
- 🖥️ **UI Tests** — Automated interface testing with XCUITest
- 🎨 **Custom UI** — Tailored visual design built for energy and engagement

---

## Tech Stack

| Layer | Technology |
|---|---|
| Language | Swift |
| IDE | Xcode |
| UI framework | UIKit / SwiftUI |
| Unit testing | XCTest |
| UI testing | XCUITest |

## Getting Started

### Prerequisites

- macOS 13+
- Xcode 15+
- iOS 16+ device or simulator

### Installation

```bash
# Clone the repository
git clone https://github.com/Swiren6/FuegoVibe-IOS_App.git
cd FuegoVibe-IOS_App
```

Open `FuegoVibe.xcodeproj` in Xcode, select a simulator or connected device, and press **Run** (⌘R).

### Running Tests

In Xcode, press **⌘U** to run the full test suite (unit + UI tests).
